# Velo Privacy Inspector

A Chrome extension that checks the page you are on for privacy issues. It opens in Chrome's side panel, so the findings sit next to the site.

This is the 0.3.0 training build. Its Consent Mode and enhanced conversions checks run live; the cookie, banner and policy checks are still sample data.

## Install the training build

1. Download `velo-privacy-inspector-0.3.0.zip` from the [latest release](https://github.com/veloconsent/velo-privacy-inspector/releases/latest).
2. Unzip it.
3. Open `chrome://extensions` and turn on Developer mode.
4. Choose Load unpacked and select the `velo-privacy-inspector-0.3.0` folder.

Requires Chrome 116 or later.
